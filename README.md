# robotics-simulation: `history` branch

This branch holds the full development history of the Byte to Bite simulation, including work that never went live (VEX controller bridge, multiplayer, start screen).

- **`main`** is the live site: https://school-user.github.io/robotics-simulation/
- **`history`** (this branch) has one commit per saved version of the game, from the first build on Sep 13, 2026 onward.

The project started before it was on GitHub, so these commits were rebuilt on Sep 29, 2026 from backups saved on the laptop. Each commit is dated when its snapshot was saved (Mountain time), and its message says which backup it came from.

See `CHANGELOG.md` on `main` for a plain-English list of every update.

Not included: the official BEST field CAD and drawings (they're BEST's files, and this repo is public), build logs, and `node_modules`.
